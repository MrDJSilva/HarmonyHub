HarmonyHub 🎵

An all-in-one music school management system.

HarmonyHub is a web-based management platform designed to help music schools, independent music teachers and lesson providers organise their daily operations.

Built using PHP, MySQL/MariaDB, JavaScript, HTML and CSS, HarmonyHub brings student management, teacher scheduling, lesson bookings, payments and administration together into one central dashboard.

Features

🎓 Student & Teacher Management

Manage student and teacher records.

Organise student enrolments and lesson information.

Keep track of lesson history and attendance.

📅 Lesson Bookings & Scheduling

Create and manage individual lesson bookings.

Schedule recurring lessons.

Support different lesson durations.

Track lesson statuses and booking history.

🎁 Custom Lesson Bundles

Create, edit and remove custom bundle offers.

Set lesson durations, booking quantities and pricing.

Manage promotional and discounted lesson packages.

Track prepaid lesson credits.

💳 Payments & Balances

Record lesson payments.

Manage prepaid credits and student balances.

Track lesson purchases and payment history.

⚙️ Administration

Administrator account management.

Database backup and restore tools.

Factory Reset and school data management.

Software updates through GitHub Releases or manual ZIP uploads.

Database schema upgrades through SQL file uploads or pasted SQL statements.

Technology Stack

Backend: PHP 8.2+

Database: MySQL / MariaDB

Frontend: HTML, CSS and JavaScript

Development environment: XAMPP

Update distribution: GitHub Releases

Who Is HarmonyHub For?

HarmonyHub is designed for music schools, private music tutors, music academies and lesson-based education businesses that want a centralised system for managing their students, teachers, bookings and payments.

Project Goal

The goal of HarmonyHub is to simplify music school administration by replacing scattered spreadsheets, manual booking records and disconnected payment tracking with a single, easy-to-use management platform.

HarmonyHub is an evolving project, with ongoing improvements to functionality, reliability and the user experience.
